# 中文编辑器

一个**用中文写代码**的 Python 编程环境（IDE）。把 Python 关键字换成中文，让你用母语编程。

基于 Python + Tkinter 开发，已打包为独立 exe —— **目标电脑不需要安装 Python**，拷走即用。

## ✨ 功能

- **中文编程**：`输出()` 代替 `print()`，`输入()` 代替 `input()`，关键字自动高亮补全
- **内置控制台**：多开 / 关闭终端，`+` / `-` 调整大小，支持 **CMD** 和 **PowerShell** 两种终端
- **代码编辑**：中文关键字高亮、行号、语法检查
- **模块导入补全**：输入 `导入` 自动补全 `import` 语句，并列出已安装的模块
- **模板系统**：一键生成 Flask、SQLite 等常用模板（可改端口、支持局域网访问）
- **文件关联**：`.cnpy` 文件双击用中文编辑器打开，自动换图标
- **安装程序**：检测重复安装、创建桌面/开始菜单快捷方式、一键卸载（bat）

## 🚀 快速开始

### 方式一：下载 exe（推荐）

从 **Releases** 页面下载最新版：

| 文件 | 说明 |
|---|---|
| `中文编辑器.exe` | 免安装版，双击即用 |
| `中文编辑器安装程序.exe` | 安装版：自动建快捷方式、关联 .cnpy 文件 |

### 方式二：从源码运行

需要 Python 3.10+：

```bash
python 源码/中文编辑器.py
```

## 🛠️ 从源码构建 exe

需要 PyInstaller：

```bash
pip install pyinstaller
pyinstaller --noconfirm 构建/中文编辑器.spec
pyinstaller --noconfirm 构建/中文编辑器安装程序.spec
```

产物在 `dist/` 目录。

## 📂 项目结构

```
中文编辑器_python/
├── 源码/       # 代码：主程序、安装程序、卸载脚本
├── 资源/       # 图标（.ico / .png）
├── 构建/       # PyInstaller 打包配置（.spec）
├── 工具/       # 辅助脚本（文件关联、快速启动）
└── dist/       # 打包产物（exe）
```
